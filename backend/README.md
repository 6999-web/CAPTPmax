# Backend Workspace

This folder now holds all backend runtime code plus backend-adjacent assets that used to be scattered at the project root.

## Suggested navigation

- `main.py`: FastAPI entrypoint
- `cv/`: CV and pose analysis engines
- `services/`: orchestration and reporting logic
- `tests/`: backend test suite
- `assets/`: sample media, case files, and imported resources
- `docs/`: architecture and deployment notes
- `ops/`: compose files, env templates, and Python dependency manifests
- `scripts/`: local Windows launch scripts
- `archive/`: legacy snapshots kept for reference during cleanup
